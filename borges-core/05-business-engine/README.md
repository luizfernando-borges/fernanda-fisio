# Business Engine

O mecanismo que aplica Rules sobre Facts, usa Models para calcular confiança, e produz Recommendations, Insights, Alerts e Actions. Não é um dos 5 Pilares — é a camada que os conecta. Templates: RULE, MODEL, RECOMMENDATION, PROMPT, INSIGHT, ALERT, ACTION.

Consulte `GOVERNANCE_Arquitetura_Borges_Core.md` (em /00-governance) para a especificação completa desta pasta, incluindo relacionamentos e convenção de IDs.
